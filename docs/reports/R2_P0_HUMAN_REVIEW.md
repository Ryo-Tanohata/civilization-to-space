# R2-P0 ブラウザレビュー報告

状態：レビュー完了。オーナーがR2-P0を受入判断済み。未実施の検証は本書に明記する。

## レビューの目的

R2-P0「生命圏の比較条件のA/B比較ビュー」が、実ブラウザで意図どおり動作し、かつ**誤読されないか**を確認する。自動検証で確認できるのは仕様に書かれた条件までであり、次の4点は画面を見て判断する必要があった。

1. 4つの比較条件が、時代順・進歩順・難易度順に見えないか
2. A/Bの差が、優劣・改善・悪化に見えないか
3. `landVegetation` の単調性が、到達点や最終進化に見えないか
4. A・Bの2つの地球が見分けられるか

あわせて、R1「Earth Through Time」に回帰が生じていないことを確認する。

## レビューの実施体制

**自動検証と画面の目視確認はAIアシスタントが実施し、受入判断はオーナーが行った。** オーナー自身による実機端末での操作は行っていない（「未実施の検証」に記載）。

[AGENTS.md](../../AGENTS.md) の「実行していないテストを合格と書かない」に従い、実施していない検証は本書で未実施として区別する。

## 修正対象となったモバイル表切れ問題

### 症状

スマートフォン幅で、比較表の4列目「差（B−A）」が右端で切れて読めなかった。

### 原因

`site/r2.css` の `#r2-table thead th` に `white-space: nowrap` が指定されていた。見出しセルは `site/r2.js` が「基準A：海洋中心・低酸素化」のような長い文字列へ差し替えるため、折り返し禁止が表の最小幅を押し広げていた。

### 自動検証が見逃した理由

自動検証はページ全体の横スクロール（`document.documentElement.scrollWidth <= clientWidth`）だけを判定していた。表の外枠 `.r2-table-wrap` に `overflow-x: auto` があるためページ自体は横に伸びず、**切れているのは枠の内側**だった。数値だけでは検出できず、実際にキャプチャを見て発見した。

### 修正コミットID

```
950ff52  fix: stop the R2 comparison table from clipping on narrow screens
site/r2.css | 7 insertions(+), 3 deletions(-)
```

### 修正内容

| 変更 | 内容 |
|---|---|
| 見出しセルの折り返し | `white-space: nowrap` を削除し、長い見出しを折り返せるようにした |
| 狭い画面の列幅 | 600px以下で `table-layout: fixed` とし、列幅を 28% / 24% / 24% / 24% に固定した |
| セル余白 | 600px以下で `7px 6px` から `6px 5px` へ詰めた |

変更は `site/r2.css` のみ。`site/index.html`・`site/r2.js`・`site/data/biosphere-scenarios.json` およびR1のファイルには触れていない。

### 修正後の確認

表の実幅を外枠の幅と突き合わせ、さらに全セルについて `scrollWidth` が `clientWidth` を超えていないことを測定した。

| 幅 | 表が枠内に収まる | セル内の文字が切れていない | ページの横スクロールなし |
|---|---|---|---|
| 320px | 通過 | 通過 | 通過 |
| 360px | 通過 | 通過 | 通過 |
| 390px | 通過 | 通過 | 通過 |
| デスクトップ | 通過 | 通過 | 通過 |

360pxのキャプチャで、4列目に「2段階／多い」「3段階／暖かい」「4段階／広い」がすべて表示されていることを目視確認した。

## 4条件の順序・優劣誤読に関する判断

### 確認したこと

4つの比較条件の選択UIを拡大して確認した。2×2の格子、番号なし、4つとも同一の見た目・同一サイズである。画面には「4件の比較条件は、時代順・進歩順・難易度順ではありません。並びに意味はなく、どれかが到達点でも失敗でもありません。」が常設表示されている。

格子配置により、「並び」ではなく「選択肢の集合」として読める。

### 残るリスク

上段の「海洋中心・**低酸素化**」→「**酸素化**の移行」には、時系列的な連想が残る。これは配置の問題ではなく、**名称そのものが持つ含意**であり、並べ替えても消えない。下段の「寒冷・氷の制約」→「陸上植生の広がり」は順序に読めない。

参考として、4条件を関連時代の `sortOrder` に写すと 2 / 2 / 3 / 4 となり単調非減少になる。ただし関連時代は画面に表示していないため、利用者がこの並びを時代順として読み取る経路はない。

### 判断

オーナー判断により、**初期版では現状を許容する**。

- 4条件の名称を変更しない
- 番号なしの2×2配置を維持する
- 「時代順・進歩順・難易度順ではない」という常設注記を維持する

## A/B地球表現の視認性に関する判断

### 確認したこと

4条件それぞれの地球を個別に拡大し、さらに5通りの組合せ（海洋中心×酸素化の移行、海洋中心×寒冷、寒冷×陸上植生、陸上植生×海洋中心、寒冷×寒冷）を並べて確認した。

| 条件 | 見え方 |
|---|---|
| 海洋中心・低酸素化 | 青い海と暗い陸。酸素化リングなし |
| 酸素化の移行 | 青い海に薄い氷の霞と、破線の酸素化リング |
| 寒冷・氷の制約 | ほぼ全面が白い氷 |
| 陸上植生の広がり | 青い海に緑の陸と、破線の酸素化リング |

### 判断

**4条件すべて明確に見分けられる。** 差が最小の組（海洋中心・低酸素化 × 酸素化の移行）でも、酸素化リングの有無で判別できる。

A・Bの地球は同サイズ・同視点・同レイヤー順（海→陸→植生→氷→陰影→酸素化リング）で描かれる。雲・火山・都市光・衛星は比較対象外として描いていない。

色だけに依存しないよう、条件名・要約・6変数の言葉・数値・表を併記している。地球には条件名と量の言葉を含む代替説明を付けている。

なお、R1でInformationとFutureが見分けにくいという課題があるが、**R2では同種の問題は生じていない**。

## landVegetationの単調性に関する判断

### 確認したこと

`landVegetation` の値は4条件で 0 / 0 / 0 / 100 となり、6変数のうちこの1つだけが単調である。`bio_land`「陸上植生の広がり」だけが陸上植生を持つという定義そのものに由来し、避けられない。

他の5変数は単調ではない。

| 変数 | 4条件の値 | 単調性 |
|---|---|---|
| oxygenationStage | 0 / 50 / 25 / 75 | 非単調 |
| liquidOceanPresence | 100 / 100 / 25 / 75 | 非単調 |
| relativeWarmth | 75 / 50 / 0 / 75 | 非単調 |
| iceCover | 0 / 25 / 100 / 25 | 非単調 |
| photosynthesisActivity | 25 / 75 / 0 / 100 | 非単調 |
| landVegetation | 0 / 0 / 0 / 100 | **単調** |

比較表は常に2条件のペアしか表示しない。4条件を通した単調性は、4つすべてを順に選んで初めて見えるものであり、その場合も他の5変数が非単調であるため、全体として進歩の順序には読めない。

### 判断

オーナー判断により、**既知の制約として受容する**。総合点、ランキング、到達点、最終進化を示す表現を追加しない。

## 既知の制約

- `landVegetation` のみ4条件で単調（前掲）
- 上段2件の名称に時系列的連想が残る（前掲）
- 「◯段階」という表記が効果量の大きさに読まれる余地がある。常設注記で打ち消している
- 比較条件の値に出典がない。全条件のデータ品質状態は「象徴表現案・出典未検証」
- 比較変数の同一性検証はJSON内で自己完結している。`variables` 配列が順序と識別の正本であり、6変数のIDを `site/r2.js` に直書きしていないため、変数名を丸ごと入れ替えたデータは検証を通過する（R1の `eraOrder` と同じ設計判断）
- R2の想定外エラー通知は1回限り。R1と同じくラッチしている
- 同一ページ上で、R1 Futureの2案は読み取り専用のまま、R2の4条件はA・Bとして選べるという非対称が残っている
