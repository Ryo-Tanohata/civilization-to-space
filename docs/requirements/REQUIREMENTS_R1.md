# R1要件：Earth Through Time

状態：レビュー用初案。実装未着手。

## 目的

6時代の地球を観察・選択・再生し、環境と文明の大きな変化を象徴的に理解する。ブラウザで体験を確認した後、同じ時代識別子とデータ項目をUnityに移す。

## 想定ユーザー

地球史や未来に関心がある一般ユーザー、体験設計をレビューする開発者。専門知識は不要。初期表示言語は日本語と仮定する。

## ユーザーストーリー

- US-01：興味のある時代へ直接移動し、見た目と短い解説を一緒に読みたい。
- US-02：順番に再生し、地球の変化を眺めたい。
- US-03：未来の複数案を比較し、予測と仮定の違いを知りたい。
- US-04：キーボードや小さい画面でも同じ操作を行いたい。

## 機能要件

| ID | 要件 |
|---|---|
| FR-01 | カタログの6時代を固定順で表示し、名称・年代ラベル・解説・地球表現を同期する |
| FR-02 | 前後移動、直接選択、6段階のスライダーを提供する |
| FR-03 | 自動再生・停止、0.5倍／1倍／2倍を提供し、最後で停止する |
| FR-04 | Future内で「協働と保全」「資源制約への適応」の2つの仮想案を選び、説明と表現を比較する |
| FR-05 | データ欠損を通知し、操作可能な安全な状態を保つ |
| FR-06 | Unityでも同じ6 IDと順序を使い、地球表示・時代切替・再生を確認する |

## 非機能要件

- NFR-01：初期モックは外部通信・有料API・追加ライブラリ不要で、ローカル起動可能とする。
- NFR-02：幅360pxからデスクトップまで主要操作が欠けず、キーボードで全操作が可能。
- NFR-03：色だけに依存せず、フォーカス表示、操作名、動きの軽減を提供する。
- NFR-04：本文のコントラスト比は4.5:1以上を設計目標とし、実装時に測定する。
- NFR-05：ユーザー入力から個人情報を収集せず、外部へ送信しない。
- NFR-06：通常の操作で未処理エラーがなく、対応ブラウザと検証環境を報告する。

## スコープ内

6時代、象徴的地球、短い説明、離散的時系列操作、Futureの説明付き2案、ブラウザレビュー、Unityでの最小再現。共有データ項目の設計を含む。

## スコープ外

高精度年代・物理・気候計算、連続的な地球史再現、詳細な文明AI、資源経済、宇宙居住シミュレーション、ユーザーアカウント、クラウド、Blender高品質素材、ECS/DOTS。Futureは定量モデルではない。

## 前提条件・合理的な仮定

Windows 11、ブラウザ、将来のUnity Personalを利用する。ブラウザはChrome／Edgeを初期検証候補とする。6時代は等間隔の操作ステップであり、実年代の長さを表さない。年代数値・出典・Unityバージョンは後続レビューで確定する。

## 科学的・表現上の限界と免責

時代は地質年代の厳密な区分ではない。色・氷・森林・ネットワークは比喩的表示であり、実際の分布や同時性を保証しない。未来案は仮定に基づく探索用で、発生確率、実現年、投資・政策判断の根拠を提供しない。史実と仮想案を画面上で区別する。

## Definition of Done

ブラウザ段階：FR-01〜05を実装し、対応する受入基準・キーボード・小画面・欠損データを検証、レビュー結果と残課題を記録する。

R1全体：上記に加えてFR-06をUnityで検証し、起動手順、データ対応表、既知の制限、レビュー承認が揃う。文書作成だけでR1完了とはしない。

## 受入基準（Given / When / Then）

| ID | Given | When | Then |
|---|---|---|---|
| AC-01 | 有効な6時代データ | 初回起動 | Hadeanで停止し、名称・説明・地球が一致する |
| AC-02 | 任意時代で停止中 | 前後・選択・スライダーを操作 | 同じ選択IDへ全表示が同期し、両端を越えない |
| AC-03 | 1倍で再生中 | 1ステップ分経過 | 次の時代へ進み、Future到達時は停止する |
| AC-04 | 再生中 | 手動選択または停止 | 再生が止まり、意図しない追加遷移が起きない |
| AC-05 | Futureを表示 | 未来案を切替 | 時代はFutureのまま、案名・説明・表現が変わる |
| AC-06 | キーボードのみ／幅360px | 主要操作を実行 | 全機能へ到達でき、フォーカスとラベルが認識できる |
| AC-07 | 必須ID欠損または重複 | 読込 | 明確なエラーと無効な操作状態を示し、クラッシュしない |
| AC-08 | 動き軽減が有効 | 起動・再生 | 装飾運動を抑え、自動開始せず、手動移動が可能 |
| AC-09 | Unityへ同じデータを導入 | 6時代を切替・再生 | ID・順序・説明がブラウザと一致する |

## リスク・未決事項

年代や人類史の省略による誤解、Futureを優劣評価と受け取る可能性、CSSとUnityの見た目差、ローカルデータ読み込み制約がある。年代出典、Unity環境、未来案の文言、測定端末を実装前にレビューする。
