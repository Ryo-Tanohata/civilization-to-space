# R2要件：生命圏の比較（R2-P0 ブラウザ）

状態：R2-P0のブラウザ実装に対応する要件。オーナーの判断により、R1のUnity最小再現（R1-P1）より先に実装した。Unity移植（R2-P1）は後続とする。

## 目的

R1「Earth Through Time」の時代観察を保持したまま、生命圏に関わる4つの固定条件を基準Aと比較Bとして選び、6つの変数で見比べられるようにする。目的は数値の当てはめではなく、「条件が違うと地球の見え方がどう変わるか」を並べて考えられるようにすることである。

## R2ではないもの

精密な地球科学、気候、進化、未来予測のモデルではない。0〜100の値は実測値でも予測値でもなく、比較のために設計した正規化された仮定である。温度・濃度・面積・種数のいずれでもない。

高い値が望ましいという意味を持たない。4件の比較条件に優劣、到達度、達成度、進歩の順序はない。

## 時代と比較条件の区別

| | 定義 | 所在 |
|---|---|---|
| 時代 | R1の時間軸上のマイルストーン。6件、順序が意味を持つ | `site/data/earth-eras.json` |
| 比較条件 | R2でAまたはBとして選ぶ固定の環境条件セット。4件、順序に意味はない | `site/data/biosphere-scenarios.json` |

R2は第7の時代を追加しない。比較条件を選んでもR1の6時代は増減しない。

R1のFutureが持つ「将来シナリオ候補」「仮想シナリオ案」とは別物である。混同を避けるため、**R2の画面UI・見出し・説明文・データ表示名では「シナリオ」「比較シナリオ」「未来シナリオ」「仮想シナリオ案」を使わない**。R2の4件は一貫して「比較条件」と呼ぶ。

## 対象の比較条件

| id | 表示名 | relatedEraId（画面には出さない） |
|---|---|---|
| `bio_ocean` | 海洋中心・低酸素化 | EarlyOcean |
| `bio_oxygenation` | 酸素化の移行 | EarlyOcean |
| `bio_ice` | 寒冷・氷の制約 | Snowball |
| `bio_land` | 陸上植生の広がり | GreenEarth |

`relatedEraId` はデータの追跡可能性のために保持するが、**画面には表示しない**。4件が時代カードや追加時代として誤読されることを避けるためである。

上記の並びはオーナー指定の列挙順であり、時代順・進歩順・難易度順ではない。画面では番号を付けず2×2の格子で並べ、順序に意味がない旨を常設表示する。

## 対象の比較変数

表示順は固定し、値でソートしない。

| # | id | 表示名 |
|---|---|---|
| 1 | `oxygenationStage` | 酸素化の段階 |
| 2 | `liquidOceanPresence` | 液体の海の表現 |
| 3 | `relativeWarmth` | 冷暖の相対状態 |
| 4 | `iceCover` | 氷の被覆表現 |
| 5 | `photosynthesisActivity` | 光合成活動の表現 |
| 6 | `landVegetation` | 陸上植生の表現 |

値は0・25・50・75・100の5段階のみとする。中間の値を許さないことで、5点刻みの分解能があるかのような誤解を避ける。各変数は5段階に対応する中立な言葉（例：なし／わずか／中くらい／広い／ほぼ全面）を持ち、画面では言葉を主、数値を従として併記する。

## 機能要件

| ID | 要件 |
|---|---|
| R2-FR-01 | 1枚のページ内でR1表示とR2表示を切り替える。R1の画面・操作・文言・時代データを変更しない |
| R2-FR-02 | 基準Aと比較Bをそれぞれ4件から選べる。同じ条件をAとBに選べる |
| R2-FR-03 | 6変数について、A値・B値・差（B−A）を同時に表示する |
| R2-FR-04 | AとBに同じ条件を選んだ場合、全変数の差を「同じ」と表示する |
| R2-FR-05 | AとBそれぞれに、同サイズ・同視点・同レイヤー順の象徴的な地球を表示する |
| R2-FR-06 | R2へ移動する際、R1が再生中なら停止する |
| R2-FR-07 | R2からR1へ戻ると、R1の選択時代と速度を保持したまま停止状態にする |
| R2-FR-08 | 同一ページ内でR2を離れて戻ると、A・Bの選択を保持する |
| R2-FR-09 | R2のデータ読込・検証に失敗した場合、R2だけを比較不能にし、R1の読込・表示・操作・再生に影響を与えない |

## 非機能要件

| ID | 内容 |
|---|---|
| R2-NFR-01 | 外部ライブラリ・CDN・npm・Node.js・フレームワーク・外部API・画像・動画・Webフォントを使わない |
| R2-NFR-02 | 幅360pxからデスクトップまで主要操作が欠けず、キーボードで全操作が可能 |
| R2-NFR-03 | 色だけで状態・差を伝えない。名称・説明・言葉・数値・表を併記する |
| R2-NFR-04 | 本文と重要な注記のコントラスト比は4.5:1以上を設計目標とする |
| R2-NFR-05 | localStorage・sessionStorage・Cookie・URLパラメータで永続保存しない。A・B選択はページのセッション内のメモリにのみ保持する |
| R2-NFR-06 | R2の例外がR1のグローバルエラーハンドラへ漏れない |
| R2-NFR-07 | `prefers-reduced-motion` を尊重する |

## 実装してはならないもの

自由な数値編集、時間積分、補間、自動再生、タイマー、保存・共有、総合点、合計、平均、順位、レーダーチャート、色による優劣評価、矢印アイコン、増減を称賛または警告する表現、未来予測、動的な因果計算。

「良い／悪い」「進歩／後退」「改善／悪化」「高いほど望ましい」といった価値判断を、比較条件名・変数名・値・差のいずれにも表示しない。これらの語を注記で使う場合は、否定文としてのみ用いる。

## データ品質

全比較条件のデータ品質状態は「象徴表現案・出典未検証」である。数値には出典がなく、レビューを経ていない。値の見直しには設計意図の再確認を要する。

各変数は「表していないもの」を明示する `limitation` を持ち、画面に表示する。

## R1との関係

- R1の6時代の意味・並び順・説明・表示仕様を変更しない
- `site/data/earth-eras.json`、`site/app.js`、`site/styles.css` を変更しない
- R2は `relatedEraId` の検証のためだけに `earth-eras.json` を読む。時代の表示名や説明を複製しない
- R2はR1の内部状態・関数・DOMマップに触れない。R1の再生停止は、公開されている再生ボタンの状態を読み、再生中のときだけ合成クリックで行う

## Definition of Done

R2-P0：R2-FR-01〜09を実装し、対応する受入基準・キーボード・小画面・データ欠損を検証し、R1の回帰がないことを確認して結果を記録する。人によるレビューはこれとは別に必要である。

R2全体：上記に加えてUnity（R2-P1）で同じ比較条件データを再現し、起動手順・データ対応表・既知の制限・レビュー承認が揃うこと。文書作成だけでR2完了とはしない。

## 受入基準（Given / When / Then）

| ID | Given | When | Then |
|---|---|---|---|
| R2-AC-01 | 有効な比較条件データ | ページを開く | R1が表示され、R2は非表示。R1はHadean・停止・1x |
| R2-AC-02 | R1を表示中 | 「生命圏の比較」を押す | R2が表示され、基準A=海洋中心・低酸素化、比較B=酸素化の移行。フォーカスがR2見出しへ移る |
| R2-AC-03 | R1が再生中 | R2へ移動する | R1の再生が停止し、以後R2に居る間も時代が進まない |
| R2-AC-04 | 任意の時代・速度でR2へ移動済み | R1へ戻る | 時代と速度が保持され、停止状態。フォーカスがR1入場ボタンへ移る |
| R2-AC-05 | A・Bを変更してR1へ戻る | 再びR2へ入る | A・Bの選択が保持されている |
| R2-AC-06 | R2を表示中 | A・Bの16通りの組合せを順に選ぶ | 条件名・要約・地球・6変数・差がすべて同期する |
| R2-AC-07 | R2を表示中 | AとBに同じ条件を選ぶ | 全6変数の差が「同じ」と表示され、2つの地球が同じ見た目になる |
| R2-AC-08 | R2データが取得不能・構文不正・スキーマ不一致・件数不一致・ID重複・値不正・関連時代不明・必須値欠損のいずれか | ページを開きR2へ移動する | R2だけがエラー表示になり、R1の読込・表示・操作・再生がすべて通常どおり動く |
| R2-AC-09 | R2がエラー状態 | R2の再読み込みを押す | 正常なデータなら比較表示が復帰し、A・Bは初期値に戻る |
| R2-AC-10 | キーボードのみ／幅360px | R2の主要操作を実行 | 切替・A・B・再読み込みへ到達でき、フォーカスとラベルが認識でき、横スクロールが出ない |
| R2-AC-11 | 動き軽減が有効 | R2を表示する | 装飾の遷移が抑制され、自動再生は存在しない |
| R2-AC-12 | R2を表示中 | 画面を読む | 象徴値・並び順・軸の区別・差の意味・省略事項の5つの注記が常設表示されている |

## リスク

| リスク | 内容 |
|---|---|
| 4件が時代順に読まれる | 指定の列挙順は関連時代のsortOrderに写すと2/2/3/4となり単調非減少になる。番号を振らず2×2で並べ、注記で打ち消しているが、人によるレビューでの確認が要る |
| 差が効果量に読まれる | 「3段階」という表記が影響の大きさに見える可能性がある。注記で打ち消しているが検証が要る |
| `landVegetation` が単調 | 4条件で 0 / 0 / 0 / 100 となり、この1変数だけは進歩順に見える。`bio_land` の定義上避けられない |
| データの出典がない | 全値が設計上の仮定であり、レビューを経ていない |
| R2がR1を巻き込む | 例外が漏れるとR1が全面停止する。実装で多重に防いでいるが、R2を拡張する際は同じ規律が必要 |

## R3への引継ぎ

比較条件という枠組みは、R3以降で扱う人類・文明の条件比較へ拡張できる。ただし本要件の範囲は生命圏の4条件に限る。変数を増やす場合、5段階という制約と「優劣を付けない」という原則を維持するか、別途判断する。

`site/data/biosphere-scenarios.json` はブラウザR2専用であり、Unityとの共通交換形式の候補ではない。R2-P1でUnityへ移す際に、R1の `earth-eras.json` と合わせて交換形式を決める。
