# ブラウザモック仕様

状態：実装承認前の初案。本書はHTML/CSS/JavaScript/JSONファイルを生成する許可ではない。

## 目的

6時代を観察・操作する体験と、説明・演出の対応をブラウザで検証する。計算モデルや3D品質より、選択・再生・停止・比較の理解しやすさを優先する。

## 画面構成とUI部品

見出し、象徴表現の注記、時代名、年代ラベル、地球表示、短い解説、時代選択、前後ボタン、再生／停止ボタン、速度選択、6段階スライダーを一画面に置く。Futureのみ未来案選択と仮定の説明を表示する。エラー領域は通常非表示とし、問題時にテキストで通知する。

## 操作仕様

| 操作 | 振る舞い |
|---|---|
| 起動 | Hadean、停止、速度1倍、未来案Cooperationで開始。自動再生しない |
| 前／次 | 1時代移動し再生を停止。Hadeanの前・Futureの次は無効。循環しない |
| 時代選択 | 指定IDへ移動し再生を停止 |
| スライダー | 0〜5の整数、刻み1。順序を示し実年代に比例しない。操作で再生停止 |
| 再生 | 1倍で1時代4秒、0.5倍で8秒、2倍で2秒。Future到達で停止 |
| Futureで再生 | Hadeanへ戻して再生。ボタン名も「最初から再生」にする |
| 停止 | 現在の時代を保持し、保留タイマーを解除 |
| 速度変更 | 再生状態を保ち、変更時点から新しい間隔で計時し直す |
| 未来案選択 | FutureのIDは維持。案名・説明・視覚だけ変更。選択はセッション内で保持 |
| 非表示タブ | 再生停止。戻っても自動再開しない |

## 状態管理

現在の時代IDまたは索引、再生中か、速度、未来案ID、データ検証状態を一箇所で管理する。表示はこの状態から導き、DOMごとに別の時代状態を持たない。タイマーは常に最大1つとし、手動移動・停止・終端・画面非表示時に解除する。更新時は地球、説明、選択、スライダー、ボタン状態をまとめて同期する。保存や外部送信は行わない。

## CSSで表現する象徴的地球

円形領域にグラデーションと重ねた層で、地表・海・氷・緑・雲・光点・接続を表現する。外部画像・フォント・ライブラリは不要。視覚パラメータは演出強度であり実測値ではない。装飾は操作を遮らず、支援技術向けには地球の意味を短い説明で提供する。

切替演出は目安300ms以内の穏やかな遷移とし、点滅や常時回転は初期対象外。動きを減らす設定では遷移を省略する。カメラは固定。地球の形と画面構造を保ち、時代ごとにレイアウトが跳ねないようにする。

## レスポンシブ対応

幅360pxから横スクロールなしで主要操作を配置する。狭い画面では1列にし、地球は画面幅に応じて縮小、操作は折り返す。200%拡大時もラベルと操作を失わない。固定高さによる説明文の切り捨てを避ける。

## アクセシビリティ

標準のボタン・選択・スライダーの意味を使う。Tab順は表示順、操作名と現在値を明示し、Enter／Spaceや矢印キーの標準操作を維持する。フォーカスを見える状態にし、操作後に勝手に移動しない。地球の色だけで時代を区別しない。状態通知は穏やかに行い、装飾の更新を読み上げない。コントラスト、拡大、動き軽減は実装時に検証する。適合認証を取得したとは表記しない。

## エラー・データ欠損

必須6 IDの欠損、重複、順序不正は全体エラーとし、再生・移動を無効にして「時代データを読み込めません」と表示する。部分的な視覚パラメータ欠損は中立の地球に置換し、表示が簡略化された旨を示す。任意のイベント文欠損は非表示。解説等の必須文字列欠損は検証エラーとする。内部パスや例外全文を利用者へ表示しない。未知のフィールドは無視し、未知の必須IDやスキーマ版は受け入れない。

## Unityへ再利用するデータ連携方針

将来、JSONを共通の交換形式候補とするが、今回は生成しない。項目案はschemaVersion、eraId、order、displayName、ageLabel、summary、visual、events、qualityStatus、scenarioOptions。visualの海・氷・植生・接続等は0〜1の無次元演出強度とし、レンダリング側でCSS／Unity表現へ変換する。CSSのクラス名やUnityのアセット参照を共通データへ混ぜない。

ID・順序・テキスト・品質状態を共通化し、両実装の見た目の完全一致は求めない。Futureの案は時代と別のIDを持つ。検証条件は必須6 ID、orderの一意性、文字列の存在、強度の範囲、スキーマ版。実装時にブラウザのローカルファイル制約を確認し、直接開けるモック用データと共通JSONの管理方法を承認する。サーバーや依存関係は自動導入しない。

## 今回の実装対象外

今回の作業は本仕様の記述だけ。後続モックでも地理的に正確な大陸、気候・資源計算、外部API、音声、ログイン、クラウド保存、Unity・Blenderアセット制作は対象外。

## テスト観点

| 分類 | 確認内容 |
|---|---|
| 初期状態 | Hadean・停止・1倍・表示の一致 |
| 境界 | 前後の端、スライダー0と5、Futureでの再生 |
| 再生 | 3速度の間隔、速度変更、連打によるタイマー重複、終端停止 |
| 手動介入 | 再生中の選択・移動・停止とタブ非表示で追加遷移がない |
| Future | 2案の説明・表現の同期、時代IDが不変 |
| 欠損 | 必須ID欠損・重複・文字列欠損、任意項目と視覚値の欠損 |
| 操作支援 | キーボードのみ、フォーカス、読み上げ、色に依存しない説明 |
| 画面 | 幅360px・デスクトップ・200%拡大・動き軽減 |
| 互換性 | Chrome／Edgeの実際の検証版を報告、外部通信なしで起動 |
| Unity移行 | ID・順序・説明の一致と不正データの拒否 |
