# R1 絵コンテ

レビュー用の7カット。操作対象は6時代。カット5・6はInformation内の一画面における導入文と接続表現として統合する。独立した第7時代や追加の再生ステップは設けない。

## 共通ワイヤーフレーム

```text
+--------------------------------------------------+
| Earth Through Time            象徴的な時代表示    |
| 時代名 / 年代ラベル                              |
|                                                  |
|             .----------------.                   |
|            (   象徴的な地球   )                  |
|             '----------------'                   |
| 短い解説 / 表現上の限界                           |
| [時代選択 v]      [未来案 v : Futureのみ]         |
| [前] [再生/停止] [次] [速度 v]                    |
| Hadean  o---o---o---o---o---o Future               |
+--------------------------------------------------+
```

## 7カット

| カット | 時代 | カメラ | 地球の見た目 | 演出 | 表示テキスト案 | 操作 | 将来のUnity実装メモ |
|---|---|---|---|---|---|---|---|
| 1 マグマ | Hadean | 正面・固定 | 赤橙の地球 | 弱い輝き。点滅なし | マグマの地球：変化の出発点 | 再生／次／時代選択 | 球体と発光表現。設定変更は別承認 |
| 2 海 | EarlyOcean | 同じ位置 | 青い面と薄い雲 | 短い色の遷移 | 海の誕生：水を持つ地球へ | 前後／停止 | 同一球体の表現切替 |
| 3 氷河 | Snowball | 同じ位置 | 白と淡い青 | 氷の層へ切替 | 全球凍結の時代：強い寒冷化の象徴 | 前後／直接選択 | 氷の被覆は演出値として扱う |
| 4 緑 | GreenEarth | 同じ位置 | 青い海と緑の斑点 | 緑が現れる | 森林と陸上生態系：陸に広がる生命 | 前後／速度 | 植生分布の正確さは対象外 |
| 5 人類・文明 | Information導入 | 同じ位置 | 少数の光点 | 6と同一状態。独立タイマーなし | 人類の活動と文明が地球の見え方を変える | Informationの操作を共有 | 後続リリースの文明表現への入口 |
| 6 情報化 | Information主表現 | 同じ位置 | 光点と接続線 | 装飾線を穏やかに表示 | 情報・地球規模接続：遠くの活動がつながる | 前後／スライダー | 通信網の実データではない |
| 7 未来分岐 | Future | 同じ位置 | 案ごとに緑と光が変化 | 最終時代で再生停止 | 未来は未確定。異なる仮定を比べる | 2案選択／前へ／再生 | シナリオIDで表現と説明を同期 |

## レビュー観点

色が変わる理由を文章でも理解できるか。7カットと6時代が混同されないか。短い解説を読む間は停止できるか。未来案を予言や文明の優劣と受け取らないか。動きの軽減時は瞬時切替でも内容が伝わるか。
