# 地表から見た時代の描き方（仕様）

対象：`unity/CivilizationToSpace/Assets/Scripts/View/SurfaceView.cs`
状態：**案。実装はまだ一部のみ。** 調査の経緯は[地表の調査報告](../reports/SURFACE_SCENE_RESEARCH.md)にある。

## なぜこの文書があるか

地表に降りると、宇宙から見ていたときには出てこなかった問いが一気に増える。
空は何色か。地面に草はあるか。木はどれくらい高いか。何が歩いているか。
家はどんな形か。**決めずに作ると、時代ごとに場当たりで描き分けることになり、
時代が増えるたびに破綻する。** 先に決める。

## 共通の決めごと

| # | 決めごと | 理由 |
| --- | --- | --- |
| 1 | **デフォルメした実物として描く。影（シルエット）では描かない** | 影だけだと何を見ているか読み取れなかった |
| 2 | **色は読みやすさのための決めであり、復元色ではない** | 化石から分かるのは骨格までで、皮膚の色も質感も分かっていない |
| 3 | **特定の種を表さない** | 首・胴・脚・尾の長さの比を変えているだけである |
| 4 | **形の語彙を増やさない** | 針葉樹・シダ・広葉樹・四つ足・二足・建物の6つ。比率と数と色だけで時代を分ける |
| 5 | **場面ごとの専用コードを書かない** | 時代はデータで与える。書き足す作りにすると必ず破綻する |
| 6 | **1日は10秒**。宇宙から見た自転と同じ | 同じ地球を離れて見るか地面から見るかの違いでしかない |
| 7 | **夜は星が出る**。加算で重ねるので昼は自然に消える | 昼夜で出し入れする処理が要らない |
| 8 | 遠いものほど空の色へ溶かす | 同じ色で塗ると重なりが一つの塊に見える |

## 寄り方は2つだけ

| 寄り | 目安 | 使う時代 |
| --- | --- | --- |
| **生きもの寄り** | 全長20mほどの四つ足が画面に収まる。目の高さ5.5m、30m手前 | マグマ〜氷期 |
| **街寄り** | 建物の並びが画面に収まる。集落は8m/20m手前、都市は58m/200m手前 | 人類〜未来、月 |

増やさない。寄り方を時代ごとに作ると、画面の意味が時代ごとに変わってしまう。

## 時代ごとの決めごと

### 1. Hadean マグマの地球（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 暗い赤褐色。**星は出さない**（塵で見えないものとする） |
| 地面 | 黒い岩。割れ目が橙に光る |
| 植物・生きもの | **なし** |
| 光 | 太陽ではなく地面が主な光源。昼夜の差を小さくする |

**表していないこと**：当時の空の色は分かっていない。ここでの色は決めである。

### 2. EarlyOcean 海の誕生（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | **青くしない。** 霞んだ灰褐色 |
| 地面 | 裸の岩。手前に水面 |
| 植物・生きもの | **なし**（陸上には出さない） |

**なぜ青くしないか**：大気に遊離した酸素がほぼ無かった時代である。大酸化事変（約24.5億年前）
より前の大気は二酸化炭素・メタン・水蒸気からなる還元的なもので、酸素は現在の10万分の1未満
だったとされる（[ASM「The Great Oxidation Event」](https://asm.org/articles/2022/february/the-great-oxidation-event-how-cyanobacteria-change)、
[ScienceDirect「The Continuing Puzzle of the Great Oxidation Event」](https://www.sciencedirect.com/science/article/pii/S0960982209011890)）。

**表していないこと**：当時の空の色そのものは確かめられていない。青くしないという判断だけが根拠を持つ。

### 3. Snowball 全球凍結の時代（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 淡く冷たい水色 |
| 地面 | 一面の氷。起伏は付けない |
| 植物・生きもの | **なし** |

### 4. GreenEarth 森林と陸上生態系（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | 土。低い被りだけ。**草原にしない** |
| 植物 | 高い木を中心に。最大で40mまで |
| 生きもの | **出さない** |

**根拠**：陸上の植物が現れるのは約4億7000万年前（中期オルドビス紀）で、当初は根も木質も葉も
種も持たない小さなものだった。森と呼べるものができるのは中期デボン紀（約3億8500万年前）で、
アルカエオプテリスは幹の直径1.5m、高さ40mに達したとみられる
（[NPS「Evolution on Land」](https://www.nps.gov/subjects/fossils/evolution-on-land.htm)、
[USGS「Paleozoic」](https://www.usgs.gov/youth-and-education-in-science/paleozoic)）。

### 5. Dinosaurs 巨大生物の時代（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | **裸の土と落ち葉。草原にしない** |
| 植物 | 針葉樹・シダ・広葉樹 |
| 生きもの | 四つ足（全長20m前後、肩の高さ4.5m前後）と二足 |

**根拠**：草が広い面積を覆うのは中新世（約2300万〜530万年前）以降で、急速に広がったのは
約700万〜600万年前とされる（[Nature Scientific Reports](https://www.nature.com/articles/s41598-019-43094-w)）。
アパトサウルスは全長約22m・肩高約4.5m（[AMNH](https://www.amnh.org/explore/ology/ology-cards/006-apatosaurus-excelsus)）。

### 6. Impact 衝突と暗い空（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 塵で暗い。**昼でも暗い。** 星は出さない |
| 地面 | 灰 |
| 植物 | 枯れた幹だけ。葉を付けない |
| 生きもの | **出さない** |

**根拠**：約6600万年前の衝突で舞い上がった塵が数年から数十年にわたり日光をさえぎり、
地表の温度は最大28度ほど下がったとされる（[NASA Science](https://science.nasa.gov/earth/deep-impact-and-the-mass-extinction-of-species-65-million-years-ago/)、
[NSF](https://www.nsf.gov/science-matters/moment-changed-earth)）。

### 7. IceAge 氷期のくり返し（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 淡く冷たい |
| 地面 | 乾いた土と雪。**苔で覆わない** |
| 植物 | **大きな木を出さない。** 草本と低木、まばらな矮性の木だけ |
| 生きもの | 毛のある大型の四つ足 |

**根拠**：最終氷期最盛期のマンモスステップは地球でもっとも広い生物群系で、スペインからカナダまで
広がっていた。**大きな木はほとんど無く**、現在のツンドラを覆う苔のじゅうたんも乏しかった。
イネ科・カヤツリグサ科と、草丈の低い草本が主で、低木の茂みと矮性の木がまばらに点在していた
（[ScienceDirect「Mammoth steppe: a high-productivity phenomenon」](https://www.sciencedirect.com/science/article/abs/pii/S0277379112003939)）。

### 8. Humans 人類の広がり（街寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | 土と草 |
| 植物 | まばらな木 |
| 建物 | **平らな屋根。隙間なく背中合わせ。道を作らない。窓を入れない。** 高さ5mほど |

**根拠**：チャタルホユック（紀元前7100年ごろ〜5950年ごろ）は日干しレンガの長方形の家が
背中合わせに詰まり、家のあいだに道が無い。屋根は平らで、屋根の穴から梯子で家へ降りた
（[UNESCO](https://whc.unesco.org/en/list/1405/)、[Çatalhöyük Research Project](http://www.catalhoyuk.com/site/architecture)）。

**表していないこと**：世界中の集落を代表するものではない。ひとつの遺跡の姿に基づく決めである。

### 9. Information 情報・地球規模接続（街寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | 土と草 |
| 建物 | 高さ50mほど、間隔を空けて道を作る、窓の帯を入れる。**夜は窓に灯りを入れる** |

**表していないこと**：特定の都市に基づいていない。人口も面積も表していない。

### 10. Future 未来の分岐（街寄り）

Information と同じ作りのまま、高さと数を上げる。**仮想シナリオ案である。**

### 11. 月面（街寄り・実装は後）

| 要素 | 決めごと |
| --- | --- |
| 空 | **昼でも黒い。星が見える** |
| 地面 | 灰色の細かい砂。明るい高地と暗い海 |
| 植物・生きもの | なし |
| 建物 | 拠点 |

**根拠**：月面のほぼ全体が炭のような灰色の細かい砂と岩（レゴリス）で覆われている。
高地は明るい白っぽい灰色、海は暗い。大気は薄すぎて光を散らさない
（[NASA Science「Moon Composition」](https://science.nasa.gov/moon/composition/)、
[NASA「What Is Lunar Regolith?」](https://science.nasa.gov/biological-physical/what-is-lunar-regolith/)）。

### 12. コロニーの内部（街寄り・実装は後）

**地平線が上へ反り返る。** 回転で重力の代わりを作る円筒の内部なので、向かいの地面が頭上にある。
土と緑と灯りを入れる。**仮想シナリオ案である。**

## データで持つ値

| 値 | 意味 |
| --- | --- |
| `SkyHigh` / `SkyLow` | 昼の空の色。夜の色は共通の定数から作る |
| `Ground` | 地面の色 |
| `Trunk` / `Foliage` / `Creature` / `Building` / `Window` | それぞれの色 |
| `NearZ` / `FarZ` / `HalfWidth` | ものを置く範囲 |
| `PlantHeight` | 植物の背の高さ |
| `BuildingHeight` / `BuildingSpacing` / `Windows` | 建物の高さ・間隔・窓の有無 |
| `Conifers` / `Ferns` / `Broadleaves` / `Quadrupeds` / `Bipeds` / `Buildings` | それぞれの数 |

これ以上増やさない。増やすときは、**形の語彙を増やさずに済むか**を先に考える。

## まだ決めていないこと

- 枯れた幹（衝突の時代）の形。いまの語彙に無い
- 毛のある四つ足（氷期）を、既存の四つ足と比率だけで描き分けられるか
- 水面の描き方（海の誕生）
- 月面と、コロニー内部の反り返る地平線
- 地面の起伏。いまは完全に平ら
