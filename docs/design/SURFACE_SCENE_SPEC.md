# 地表から見た時代の描き方（仕様）

対象：`unity/CivilizationToSpace/Assets/Scripts/View/SurfaceView.cs`
状態：**案。実装はまだ一部のみ。** 調査の経緯は[地表の調査報告](../reports/SURFACE_SCENE_RESEARCH.md)にある。

## なぜこの文書があるか

地表に降りると、宇宙から見ていたときには出てこなかった問いが一気に増える。
空は何色か。地面に草はあるか。木はどれくらい高いか。何が歩いているか。
家はどんな形か。**決めずに作ると、時代ごとに場当たりで描き分けることになり、
時代が増えるたびに破綻する。** 先に決める。

## 共通の決めごと

| # | 決めごと | 理由 |
| --- | --- | --- |
| 1 | **デフォルメした実物として描く。影（シルエット）では描かない** | 影だけだと何を見ているか読み取れなかった |
| 2 | **色は読みやすさのための決めであり、復元色ではない** | 化石から分かるのは骨格までで、皮膚の色も質感も分かっていない |
| 3 | **特定の種を表さない** | 首・胴・脚・尾の長さの比を変えているだけである |
| 4 | **形の語彙を増やさない** | 針葉樹・シダ・広葉樹・枯れた幹・岩・四つ足・二足・建物の8つ。比率と数と色だけで時代を分ける |
| 5 | **場面ごとの専用コードを書かない** | 時代はデータで与える。書き足す作りにすると必ず破綻する |
| 6 | **1日は10秒**。宇宙から見た自転と同じ | 同じ地球を離れて見るか地面から見るかの違いでしかない |
| 7 | **夜は星が出る**。加算で重ねるので昼は自然に消える | 昼夜で出し入れする処理が要らない |
| 8 | 遠いものほど空の色へ溶かす | 同じ色で塗ると重なりが一つの塊に見える |

## 寄り方は2つだけ

| 寄り | 目安 | 使う時代 |
| --- | --- | --- |
| **生きもの寄り** | 主役が画面に収まる。目の高さと距離は**その時代の背丈から出す**（恐竜の時代でちょうど良かった比をそのまま使う） | マグマ〜氷期 |
| **街寄り** | 建物の並びが画面に収まる。集落は8m/20m手前、都市は58m/200m手前 | 人類〜未来、月 |

増やさない。寄り方を時代ごとに作ると、画面の意味が時代ごとに変わってしまう。

ただし**距離は固定しない**。30m手前で固定していたときは、草木が9mしかない氷期で
すべてが地平線上の粒になり、画面が空と地面だけになった。獣が草木よりずっと低い時代
（氷期：獣3.6m・草木9m）は、草木ではなく**獣に合わせて近づく**。

## 時代ごとの決めごと

### 1. Hadean マグマの地球（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 暗い赤褐色。**星は出さない**（塵で見えないものとする） |
| 地面 | 黒い岩。割れ目が橙に光る |
| 植物・生きもの | **なし** |
| 光 | 太陽ではなく地面が主な光源。昼夜の差を小さくする |

**表していないこと**：当時の空の色は分かっていない。ここでの色は決めである。

### 2. EarlyOcean 海の誕生（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | **青くしない。** 霞んだ灰褐色 |
| 地面 | 裸の岩。手前に水面 |
| 植物・生きもの | **なし**（陸上には出さない） |

**なぜ青くしないか**：大気に遊離した酸素がほぼ無かった時代である。大酸化事変（約24.5億年前）
より前の大気は二酸化炭素・メタン・水蒸気からなる還元的なもので、酸素は現在の10万分の1未満
だったとされる（[ASM「The Great Oxidation Event」](https://asm.org/articles/2022/february/the-great-oxidation-event-how-cyanobacteria-change)、
[ScienceDirect「The Continuing Puzzle of the Great Oxidation Event」](https://www.sciencedirect.com/science/article/pii/S0960982209011890)）。

**表していないこと**：当時の空の色そのものは確かめられていない。青くしないという判断だけが根拠を持つ。

### 3. Snowball 全球凍結の時代（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 淡く冷たい水色 |
| 地面 | 一面の氷。起伏は付けない |
| 植物・生きもの | **なし** |

### 4. GreenEarth 森林と陸上生態系（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | 土。低い被りだけ。**草原にしない** |
| 植物 | 高い木を中心に。最大で40mまで |
| 生きもの | **出さない** |

**根拠**：陸上の植物が現れるのは約4億7000万年前（中期オルドビス紀）で、当初は根も木質も葉も
種も持たない小さなものだった。森と呼べるものができるのは中期デボン紀（約3億8500万年前）で、
アルカエオプテリスは幹の直径1.5m、高さ40mに達したとみられる
（[NPS「Evolution on Land」](https://www.nps.gov/subjects/fossils/evolution-on-land.htm)、
[USGS「Paleozoic」](https://www.usgs.gov/youth-and-education-in-science/paleozoic)）。

### 5. Dinosaurs 巨大生物の時代（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | **裸の土と落ち葉。草原にしない** |
| 植物 | 針葉樹・シダ・広葉樹 |
| 生きもの | 四つ足（全長20m前後、肩の高さ4.5m前後）と二足。**首と尾を長く取る** |

**根拠**：草が広い面積を覆うのは中新世（約2300万〜530万年前）以降で、急速に広がったのは
約700万〜600万年前とされる（[Nature Scientific Reports](https://www.nature.com/articles/s41598-019-43094-w)）。
アパトサウルスは全長約22m・肩高約4.5m（[AMNH](https://www.amnh.org/explore/ology/ology-cards/006-apatosaurus-excelsus)）。

### 6. Impact 衝突（生きもの寄り）

**この場面だけは、途中で世界が変わる。**

**5つの場面をこの順でたどる。** どれも調べたことを絵に落とした簡略化であり、
規模・年数・温度・濃さの数値は表していない。

| # | 場面 | 空 | 地面 | 植物・生きもの | 降るもの | 何にならったか |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 生きた森 | 青（上が濃く下が淡い） | 裸の土 | 恐竜の時代と同じ | なし | 白亜紀末まで恐竜がいた |
| 2 | 落ちてくる | 青 | 裸の土 | 同じ | なし | 直径10〜14kmの小天体 |
| 3 | 閃光 | 青 → 赤黒い | 灰 | **枯れた幹だけ** | 少し | 衝突 |
| 4 | **塵がおおう** | **上下の差が消え、平らなふたになる。暗くなっていく** | 灰 | 枯れた幹だけ | 灰色の塵（増えていく） | **塵が地球をおおい日光をさえぎった** |
| 5 | 凍る | 冷たい灰色 | 白っぽい | 枯れた幹だけ | 白い粒 | 年平均が氷点下、氷冠が広がった |

**「太陽をさえぎった」をどう描くか**。3つを同時に進める。

1. **空の上下の差を消す。** 晴れた空は上が濃く下が淡い。おおわれた空はその差が無くなり、
   一枚のふたのように見える。これで「ふさがれた」ことを伝える
2. **日光を段階的に落とす。** 一段で暗くすると暗幕を下ろしたように見えて理由が読めない。
   塵が増えるのに合わせて落とすと、塵が日光をさえぎったのだと分かる
3. **降る塵を増やしていく。** 一度に満ちさせず、濃くなるにつれて数を増やす

**降るものは色だけで灰から白へ移す。** 形を変えず、色と明るさだけで
「塵が降る空」から「凍る空」への移り変わりを見せる。

**1段階につき1回だけ落ちる。** 周期でくり返していたころは、枯れた世界がまた生き返って
もう一度落ちてきた。起きたことが取り消されたように見える。**U-56** で見張っている。

**落ちたあとに半分以上の時間を使う。** 落ちてくるところは一瞬でよく、
塵が広がって暗くなり、冷えて凍るまでを見せるほうが時間を要る。

| 進み具合 | 何が起きるか |
| --- | --- |
| 0.00〜0.42 | 生きた森。空を横切って落ちてくる |
| 0.42〜0.48 | 閃光。世界が枯れる。ここで揺れる |
| 0.43〜0.60 | 粉塵の柱が立ちのぼって薄れる |
| 0.44〜0.64 | 塵が空をおおい、日光が落ちていく |
| 0.62〜0.88 | 冷えていく。空も地面も降るものも白へ寄る |
| 0.88〜1.00 | 凍ったまま保つ |

**火は描かない。** K–Pg境界の粘土にはすすと炭化物があり火が走ったことを示すが、
全球同時に燃えたかは議論がある。地表を赤く焼く案は作って確かめたうえで取り下げた。
**ここでは「塵が地球をおおって日光をさえぎった」という見方一つに絞っている。**

落ちる前は**前の時代とまったく同じ姿**にする。同じ森、同じ生きもの、同じ寄り方である。
変わるのは落ちたあとだけ。

**なぜそうするか**：はじめ、この場面は最初から枯れた幹と暗い空で作っていた。
隕石がまだ空にあるのに地上はすでに死んでおり、**原因より先に結果が出ていた。**
そのため恐竜→隕石→氷期という順につながって見えず、見ている側には
「隕石のあとに恐竜がいる」ように映った。**U-46** で見張っている。

**冷えていくところまで見せる**：衝突後に「衝突の冬」と呼ばれる寒冷化があったことは
共通しているが、**何が主に冷やしたのかは文献で分かれている。**

| 研究 | 主因 | 数値 |
| --- | --- | --- |
| [Brugger ほか 2017, Geophysical Research Letters](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/2016GL072241) | 硫酸エアロゾル | 世界の年平均気温が**少なくとも26℃**低下。年平均が氷点下の年が**3年ほど**（滞留時間しだいで3〜16年）。回復に**30年**あまり。**氷冠が広がった** |
| [Senel ほか 2023, Nature Geoscience](https://www.nature.com/articles/s41561-023-01290-4) | 細かいケイ酸塩の塵 | 塵の大気中滞留が**15年**。世界平均気温が**最大15℃**低下。光合成が**2年ちかく**停止 |

前者は「塵は比較的すぐ落ちるので長い寒冷化への寄与は小さい」とし、後者は「塵の寄与は
これまでの見積もりより大きい」とする。**画面に出す降るものは、どちらかを主張するものではない。**
空が暗くなるだけでは何におおわれたのか読めないため、舞い上がったものが降ってくることを
読ませるための代表として出している。**地面を白くしているのは「氷冠が広がった」
「年平均が氷点下の年が続いた」にならったものである。U-48** で見張っている。

小天体の大きさは直径**10〜14km**ほど（[NASA JPL](https://www.jpl.nasa.gov/news/a-smoking-gun-for-dinosaur-extinction/)）。

**火を描かなかった理由**：K–Pg境界の粘土には大量のすすと炭化物（フジナイト・
多環芳香族炭化水素・炭化した植物片・木炭）が含まれ、いくつかの大陸域を火が走ったことを示す。
放出物が大気へ再突入するときの熱で数時間のうちに火がついたとされる。
ただし**全球で同時に燃えたかどうかは議論がある。** 熱の分布が一様でないこと、
北米の一部で木炭が見つからないことが根拠に挙げられる
（[Morgan ほか 2013, J. Geophys. Res. Biogeosciences](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/2013JG002428)、
[Robertson ほか 2013](https://agupubs.onlinelibrary.wiley.com/doi/full/10.1002/jgrg.20018)）。
**議論のあるものを絵の中心に置かない。**
中心は「塵が地球をおおって日光をさえぎった」（Senel ほか 2023）に置いている。

**これは「衝突の冬」であり、次の時代の氷期とは別の出来事である。**
衝突の冬は数年から数十年、第四紀の氷期は
[約259万年前](https://www.britannica.com/science/Quaternary)から現在まで続いている。
年数も気温も画面では表していない。

**根拠**：約6600万年前の衝突で舞い上がった塵が数年から数十年にわたり日光をさえぎり、
地表の温度は最大28度ほど下がったとされる（[NASA Science](https://science.nasa.gov/earth/deep-impact-and-the-mass-extinction-of-species-65-million-years-ago/)、
[NSF](https://www.nsf.gov/science-matters/moment-changed-earth)）。

### 7. IceAge 氷期のくり返し（生きもの寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 淡く冷たい |
| 地面 | 乾いた土と雪。**苔で覆わない** |
| 植物 | **大きな木を出さない。** 草本と低木、まばらな矮性の木だけ |
| 生きもの | 毛のある大型の四つ足。**首と尾は短く、脚は太く、牙を付ける** |

**根拠**：最終氷期最盛期のマンモスステップは地球でもっとも広い生物群系で、スペインからカナダまで
広がっていた。**大きな木はほとんど無く**、現在のツンドラを覆う苔のじゅうたんも乏しかった。
イネ科・カヤツリグサ科と、草丈の低い草本が主で、低木の茂みと矮性の木がまばらに点在していた
（[ScienceDirect「Mammoth steppe: a high-productivity phenomenon」](https://www.sciencedirect.com/science/article/abs/pii/S0277379112003939)）。

**首の長い四つ足を立たせてはいけない。** 非鳥類型の恐竜は白亜紀の終わり（約6600万年前）の
大量絶滅で絶滅しており、生き残ったのは鳥類と小型の哺乳類である
（[NPS「Mass Extinctions Through Geologic Time」](https://www.nps.gov/subjects/fossils/mass-extinctions-through-geologic-time.htm)）。
氷期はその約6400万年あとであり、**隕石が落ちたあとの画面に恐竜がいるのは誤りである**。
ケナガマンモスは肩の高さ3〜3.5m・体重4〜6tで、現在のアフリカゾウとほぼ同じ大きさ
（[ロンドン自然史博物館](https://www.nhm.ac.uk/discover/were-all-mammoths-woolly.html)）。
これに合わせて肩の高さ3.2mほどを狙い、胴を太く、首と尾を短く取っている。

この誤りは形が1つしか無かったために起きた。四つ足の比（首・尾・脚・牙）を時代ごとの表に置き、
**U-45**（衝突より後の時代に首の長い四つ足がいない）で機械的に見張っている。

### 8. Humans 人類の広がり（街寄り）

| 要素 | 決めごと |
| --- | --- |
| 空 | 青 |
| 地面 | 土と草 |
| 植物 | まばらな木 |
| 建物 | **平らな屋根。隙間なく背中合わせ。道を作らない。窓を入れない。** 高さ5mほど |

**根拠**：チャタルホユック（紀元前7100年ごろ〜5950年ごろ）は日干しレンガの長方形の家が
背中合わせに詰まり、家のあいだに道が無い。屋根は平らで、屋根の穴から梯子で家へ降りた
（[UNESCO](https://whc.unesco.org/en/list/1405/)、[Çatalhöyük Research Project](http://www.catalhoyuk.com/site/architecture)）。

**表していないこと**：世界中の集落を代表するものではない。ひとつの遺跡の姿に基づく決めである。

### 12. コロニーの内部（街寄り・実装は後）

**地平線が上へ反り返る。** 回転で重力の代わりを作る円筒の内部なので、向かいの地面が頭上にある。
土と緑と灯りを入れる。**仮想シナリオ案である。**

## データで持つ値

| 値 | 意味 |
| --- | --- |
| `SkyHigh` / `SkyLow` | 昼の空の色。夜の色は共通の定数から作る |
| `Ground` | 地面の色 |
| `Trunk` / `Foliage` / `Creature` / `Building` / `Window` | それぞれの色 |

## 実装して分かったこと（語彙が2つ増えた）

作ってみたところ、6つでは足りず2つ足した。どちらも**1つで複数の場面を助ける**ことを
確かめてから足している。1場面のために1つ足すやり方は採っていない。

| 足したもの | なぜ必要だったか | 使う場面 |
| --- | --- | --- |
| 枯れた幹 | 葉のある木の数を0にしても「葉が落ちた幹だけが立つ」姿にはならない | 衝突 |
| 岩 | 植物も生きものも置かない時代が3つあり、**空と地面の色の帯だけ**になって何も読めなかった | マグマ・最初の海・全球凍結・氷期（将来は月面） |

## 地表で起きる出来事

止まった風景だけでは、その時代に何が起きたのかが伝わらない。次の2つを動かす。

| 出来事 | 出る時代 | 見せ方 |
| --- | --- | --- |
| 落ちてくるもの | マグマの地球、衝突と暗い空 | 尾を引いて落ち、地平線で光り、粉塵の柱が立ちのぼる。ぶつかった瞬間は画面が揺れる |
| 打ち上げ | 情報、未来 | 街より手前の台から、噴射とともに加速して上がる |

**周期は1段階を見ている長さに合わせる。固定の秒数にしない。**
はじめ14秒や26秒の周期にしていたが、1段階は1倍速で4秒しかない。
再生していると落ちきる前に次の時代へ移ってしまい、**一度も見られなかった。**
段階の長さに合わせれば、再生中でも停止中でも、速度を変えても必ず一巡する。

**どちらも実際の大きさ・速さ・高度・間隔を表していない。** 出来事の順序だけである。

宇宙の側でも同じ出来事を見せている。地表へ降りると結果しか無いのでは、
同じ出来事を見ている感じにならない。

## 空と遠景

**空を1色の帯で終わらせない。** 上下のぼかしだけでは、どこまでが空でどこからが遠景か
分からず、板を1枚立てたように見えていた。3つの層を重ねて奥行きを出す。

| 層 | 何を出すか | どう動くか |
| --- | --- | --- |
| 空の帯 | 上下のぼかし | 毎こま塗り直す（128点だけなので軽い） |
| 雲 | 粗さの違う波を5つ重ねた形。横に伸ばす | **形は作ったときのまま。時刻では色だけ変える** |
| 太陽 | 小さな丸と広い暈 | 高さを時刻で動かす。地平線より下では引っ込める |
| 山なみ | 重なる稜線3層 | 動かさない。奥ほど空の色へ溶かす |

**雲を毎こま描き直さない。** 512×256の点を打ち直すことになり重い。
形は変わらなくてよく、変わるのは明るさと色だけなので、色の指定を1回書き換えるだけにする。

**太陽は光の向きをそのまま写さない。** 写すと真昼に画面の外の真上へ行き、
いちばん明るい時刻にいちばん見えなくなる。高さを縮めて、昇って沈むことだけを読ませる。
**実際の視直径でも位置でもない。**

**山なみは空の色へ寄せすぎない。** 空と同じ色まで薄めると、山ではなくただの霞に見えて
稜線の形が読めない。手前の稜線ほど濃く残す。**実在の地形ではない。**

塵がおおっているあいだは、雲も太陽も沈める。日光をさえぎるほどの塵なら、
雲の形も日輪も見えない。

## 1段階の長さ

| 段階 | 1倍での長さ | 理由 |
| --- | --- | --- |
| 形成過程 | 8秒 | 近づく→ぶつかる→砕ける→丸く戻る、をひと続きで見せる |
| **地表から見る時代** | **9秒** | 昼夜が一巡するのに10秒。衝突も落ちて冷えるまでひと続き |
| 宇宙から見る時代 | 4秒 | 地球の姿が移り変わるだけ。長く取っても見えるものが増えない |

**U-53** で、地表の時代が宇宙の時代より長いことを見張っている。

## 場面の切り替わり

**溶明でつなぐ。** 時代が移るたびに風景は丸ごと作り直され、カメラも一瞬で別の場所へ飛ぶ。
前の絵と次の絵のあいだに何も無いと、つながって見えない。

作り直す直前にカメラの絵を1枚控え、画面いっぱいに重ねて薄れさせる。
裏で新しい場面ができあがるので、前の絵から次の絵へ溶けるように移る。
暗転を挟む手もあるが、昼の明るい風景では重く感じる。

地表と宇宙の行き来も同じ仕組みでつなぐ。**U-54・U-55** で見張っている。

## 既定の視点

| 時代 | 既定 | 理由 |
| --- | --- | --- |
| 3〜8（森林〜情報） | **地表** | 起きていることが地上にある。8は打ち上げが地上の出来事だから |
| 0〜2、9以降（マグマ〜未来・月・ラグランジュ） | 宇宙 | 見どころが地球ぜんたい、または地球の外にある |

どちらもボタン1つで切り替えられる。既定は「切り替えなくても見どころが映る」向きに置く。

**打ち上げは街並みの中に置かない。** 機体を街の中へ置いていたとき、
建物と同じ白さで同じ高さに立ち、**地面から離れるところが見えなかった。**
建物がまだ始まらないいちばん手前の草地に置き、濃い帯と足もとの噴煙を付ける。

**出来事は既定の視点に置く。** ロケットは地表にしか出ないため、
宇宙が既定の時代にだけ置いていたときは、切り替えない限り一度も見られなかった。
**U-47** で、切り替えなくても打ち上げが見える時代が1つ以上あることを見張っている。

## 地面の起伏

**Unity の Terrain をコードから組み立てる。手で塗らない。**
時代ごとに地面を手で描くと、時代を足すたびに手作業が増え、
データから組み立てるという作りが崩れる。

| 決めごと | 理由 |
| --- | --- |
| 高さは `GroundHeight(x, z)` から引く | 置くものと同じ式を通すので、丘の斜面でも木や生きものが浮かない |
| 材質は Terrain の既定を使わない | 既定の地形用シェーダーは塗り分けの絵を要求し、WebGLに残るかも確かめにくい。この作品で実績のある自前のシェーダーを割り当てる |
| 当たり判定は外す | 誰も歩かないし、当たりを取る相手もいない |
| 起伏を持たない時代は帯のまま | 水面や溶けた地面は平らでよい |

**実在の地形ではない。**

**WebGLで描けることを確かめてから入れた。** TerrainModule はビルドに含まれ、
成果物は 9.86MB から 10.02MB（+0.16MB）になった。

## 外から持ってきた形

木・草・岩は [Kenney Nature Kit](https://kenney.nl/assets/nature-kit) の
低ポリモデルを使っている。330点のうち10点だけを取り込んだ（354KB）。

**ライセンスは CC0。** 同梱の License.txt に
「personal, educational and commercial projects で自由に使える／クレジット不要」
と明記されている。公開リポジトリへ置いても問題ない。

| 決めごと | 理由 |
| --- | --- |
| **素材側の色を連れてこさせない** | そのまま置くと水色の木や桃色の幹が並び、時代ごとに決めた色調から外れる |
| 面ごとの役を材質名から読む | Kenney の素材は `leafsGreen` / `woodBark` / `grass` / `dirt` のように名前が中身を表している |
| 面が複数あるものは面ごとに塗る | 1つ目だけ差し替えると、2つ目の面に素材側の色が残る |
| 高さをそろえる | 素材ごとに元の大きさがまちまちなので、置くときの高さに合わせて拡げ縮めする |
| 素材が無ければ従来どおり | 球と円錐で組み立てる道は残してある |

**生きものは素材に無い。** 恐竜もマンモスも自作のままで、木とは絵柄が揃っていない。

## いまも計算で描いているもの

空（帯・雲・太陽）、山なみ、地面の起伏、降る塵、ロケット、生きもの、建物、星空。
外から持ってきたのは木・草・岩の形だけである。

## 外部の素材の扱い

| 手段 | 使えるか | なぜ |
| --- | --- | --- |
| Terrain（コード生成） | **使う** | 外部素材が要らない。起伏・置き場所の一致・WebGL動作を確かめた |
| Asset Store の素材 | 使わない | 公開リポジトリへの素材そのものの再配布は多くの規約で禁じられる。容量も数十MB規模。「画面に出る絵はすべて計算で描く」という原則に反する |
| [PLATEAU SDK for Unity](https://github.com/Project-PLATEAU/PLATEAU-SDK-for-Unity) | 使えない | SDKはMITだが、**対応プラットフォームに WebGL が無い**（Windows / macOS / Android / iOS）。都市データも範囲を絞る前で数GB規模。この作品の都市は特定の実在都市ではない |

## まだ決めていないこと
- 水面の描き方（海の誕生）
- 月面と、コロニー内部の反り返る地平線
- 地面の起伏。いまは完全に平ら
