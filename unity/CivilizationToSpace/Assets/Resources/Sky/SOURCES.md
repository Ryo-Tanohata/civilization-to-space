# 遠景の写真の出どころ

**すべて [Poly Haven](https://polyhaven.com/hdris)（CC0）の全天球写真から切り出したものです。**

CC0 なので、商用利用・改変・再配布が自由で、クレジットの表示も求められていません。
公開リポジトリに置くことに問題はありません。

| ファイル | もと | 使う時代 |
| --- | --- | --- |
| `backdrop_forest.jpg` | [misty_pines](https://polyhaven.com/a/misty_pines) | 3 森林と陸上生態系 |
| `backdrop_dry_scrub.jpg` | [goegap](https://polyhaven.com/a/goegap) | 4 巨大生物の時代 / 5 衝突 |
| `backdrop_snow_steppe.jpg` | [snowy_field](https://polyhaven.com/a/snowy_field) | 6 氷期 |
| `backdrop_meadow.jpg` | [meadow_2](https://polyhaven.com/a/meadow_2) | 7 人類の広がり |
| `backdrop_wide_plain.jpg` | [rustig_koppie](https://polyhaven.com/a/rustig_koppie) | 8 情報と接続 / 9 未来の分岐 |

## 何を表していないか

**どれも現在の地球の写真です。** 白亜紀の写真も、氷期の写真も存在しません。

ここで表しているのは、その時代の**形**だけです。

| 表しているもの | 表していないもの |
| --- | --- |
| 乾いた広い野と、遠くの丘 | 白亜紀の植生・地形 |
| 木が密に立ち並ぶ奥行き | 石炭紀や白亜紀の森 |
| 雪におおわれた野と、まばらな裸の木 | 氷期の景観 |
| 草地と、その向こうの林 | アナトリアの新石器時代の風景 |
| 高いところから見下ろす広い野 | 実在の都市とその地形 |

**写真の光は動きません。** 時刻が移ると、絵の上から色を掛けて夜や朝夕にしていますが、
**影の向きは写真に焼き付いたままです。** そこは表せていません。

## なぜ全天球のまま貼らないのか

画面に映るのは 82度 x 52度ほどで、全天球（360度 x 180度）のごく一部です。
球のまま貼ると、見えない部分に画素のほとんどを使うことになり、
2048x1024 でも映る範囲は 466 画素幅しかなく、ぼやけます。

**カメラは時代ごとに決まった場所から動かない**ので、あらかじめ映る範囲だけを
切り出せば、同じ容量でずっと細かく出せます。1600 x 760 で 0.2〜0.4 MB です。

## 作り直し方

作業用の手順は `scratchpad/sky/` にあります（リポジトリ外）。

1. `make.py` — Poly Haven の API から全天球の JPG を取り、空の板に映る範囲を切り出す
2. `batch.py` — 時代ごとにまとめて作る

**切り出しは空の板の位置から逆算しています。**
`SurfaceView.BuildSky` の板の置き方（`distance = FarZ * 2.2`、`localScale = (4d, 1.9d, 1)`、
`localPosition = (0, 0.36d, d)`）と `SurfaceCatalog.EyeForEra` のカメラの位置を使っています。
**そのどちらかを変えたら、写真も作り直さないと地平線がずれます。**

太陽は、場面の光と合うように**画面の左（-35度）へ来るまで全天球を回して**から切り出しています。
