## なぜ木だけ絵に焼いたのか

**写真計測の木は、面を減らすと葉が成立しません。**

木の葉は1枚ずつの板に絵を貼ったものです。面を潰す方式（Decimate Collapse）は
近い頂点どうしをくっつけるので、別々の板がつながって崩れ、切り抜いたあとに
何も残りません。実際、葉が1枚も出ない木になりました。

板を丸ごと間引く方式に変えても、**29,781枚 → 600枚（2%）** では樹冠に対して
疎らすぎて枝だけに見えます。茂って見えるには5,000枚ほど要り、
それだと木1本で 4〜5 MB になります。

そこで**木を丸ごと1枚の絵に焼き、板に貼って**います。葉の茂りは絵の中に
残るので、面は2つで済み、容量は絵の分だけになります。板は常にカメラのほうを
向きます（縦は倒しません）。

**近づけば板だと分かります。** この作品では木は常に遠くにあり、カメラも
時代ごとに決まった場所から動かないので成り立っています。

## 作り直し方

作業用の手順は `scratchpad/ph/` にあります（リポジトリ外）。

1. `prepare.py` — Poly Haven の API から 1k の FBX と色の絵を取得
2. `tree/reduce.py` — Blender で面を減らす。葉は板ごと間引く
3. `tree/impostor.py` — Blender で1枚の絵に焼く（正射影・カメラ側から弱く照明）

Blender は 5.2 を使いました。
