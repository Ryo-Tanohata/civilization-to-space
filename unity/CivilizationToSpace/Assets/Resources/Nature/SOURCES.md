## なぜ木だけ絵に焼いたのか

**写真計測の木は、面を減らすと葉が成立しません。**

木の葉は1枚ずつの板に絵を貼ったものです。面を潰す方式（Decimate Collapse）は
近い頂点どうしをくっつけるので、別々の板がつながって崩れ、切り抜いたあとに
何も残りません。実際、葉が1枚も出ない木になりました。

板を丸ごと間引く方式に変えても、**29,781枚 → 600枚（2%）** では樹冠に対して
疎らすぎて枝だけに見えます。茂って見えるには5,000枚ほど要り、
それだと木1本で 4〜5 MB になります。

そこで**木を丸ごと1枚の絵に焼き、板に貼って**います。葉の茂りは絵の中に
残るので、面は2つで済み、容量は絵の分だけになります。板は常にカメラのほうを
向きます（縦は倒しません）。

**近づけば板だと分かります。** この作品では木は常に遠くにあり、カメラも
時代ごとに決まった場所から動かないので成り立っています。

## 作り直し方

作業用の手順は `scratchpad/ph/` にあります（リポジトリ外）。

1. `prepare.py` — Poly Haven の API から 1k の FBX と色の絵を取得
2. `tree/reduce.py` — Blender で面を減らす。葉は板ごと間引く
3. `tree/impostor.py` — Blender で1枚の絵に焼く（正射影・カメラ側から弱く照明）

Blender は 5.2 を使いました。

## 使わなくなった素材

**Gobkit（CC0）の恐竜3体は外した。** 大きな白目と笑った口が形に焼き付いており、
色を落ち着かせても漫画寄りの印象が消えなかった。同じ役は `sdf_` の3種が担う。
ライセンス上は問題が無かったので、必要になれば同じ手順で戻せる。

## 距離関数から焼いた獣（sdf_）

**外から持ってきた素材ではなく、このリポジトリの試作から焼いたものです。**
ライセンスの確認は要りません。

| ファイル | もと | 加工 | 面 | 容量 |
| --- | --- | --- | --- | --- |
| `sdf_mammoth.obj` + `.mtl` | [試作](../../../../../docs/prototypes/mammoth.html)のマンモス | 格子2.8cmで網目にし、面を減らした | 7,000 | 0.39 MB |
| `sdf_rhino.obj` + `.mtl` | 同じ試作のケサイ | 格子2.0cmで網目にし、面を減らした | 6,000 | 0.33 MB |
| `sdf_sauropod.obj` + `.mtl` | 首と尾の長い四つ足 | 格子3.5cmで網目にし、面を減らした | 4,500 | 0.25 MB |
| `sdf_ceratopsian.obj` + `.mtl` | 角と襟飾りのある四つ足 | 格子2.2cmで網目にし、面を減らした | 4,500 | 0.25 MB |
| `sdf_theropod.obj` + `.mtl` | 二本足の大型 | 格子2.4cmで網目にし、面を減らした | 4,500 | 0.25 MB |
| `sdf_person.obj` + `.mtl` | 立っている人 | 格子1.0cmで網目にし、面を減らした | 2,500 | 0.14 MB |
| `sdf_tetrapod.obj` + `.mtl` | 低く這う四肢動物 | 格子1.0cmで網目にし、面を減らした | 3,000 | 0.16 MB |

焼き方は [bake_creatures.py](../../../../../docs/prototypes/bake_creatures.py)。
`python3 bake_creatures.py 出力先` で5つとも作り直せる（scikit-image と
fast-simplification が要る）。

**人には顔も服も髪もない。** 目・鼻・口を置けば必ずどこかの顔立ちに寄るので、
作っていない。肌の色はその時代の地面の色から作る。色を選ぶこと自体が、
どの集団かの表明になるためである（[地表の描き方](../../../../../docs/design/SURFACE_SCENE_SPEC.md)の決めごと9）。

**中生代の3種は毛皮を持たない。** 表面の揺らぎを引かないので、
氷期の2種より面が少なくて足りる。角を持たない竜脚類と獣脚類は、
第2の材質を遠くへ置いて面が振られないようにしてある。

**なぜ焼いたか。** 試作は距離関数を毛の分だけ外へ押し出して毛皮にしている。
Unity の地表は球と円柱の組み立てなので、それができなかった。同じ距離関数を
格子で評価して表面を取り出せば、毛皮の盛り上がりと腹の下の裾が網目に残る。

**立ち姿で固めてある。** 地表の生きものは動かさない。対角の脚を少し前後にずらしてある。

**向き。** 前はUnityの+Z、足の裏はy=0。UnityはOBJのXを反転して読むので、
書き出すときに反転してある。材質は `creature`（胴と毛皮）と `tusk`（牙と角）の2つ。

**表していないこと。** 毛の色と長さは推定である。形は試作の比であり、
特定の個体や復元を写したものではない。
